Programar una auditoría

Programa una solicitud aprobada y registra el mismo horario para todos los auditores que ya fueron asignados a esa empresa.

1. Programar una auditoría

Prevención de cruces
ℹ ¿Qué hace esta sección? Selecciona la solicitud de la empresa una sola vez. El sistema muestra todos los auditores asignados y registra la misma fecha, modalidad y franja horaria en la agenda de cada uno. Antes de guardar, comprueba la disponibilidad de todos los integrantes del equipo.

Cada solicitud aparece una sola vez, aunque tenga varios auditores asignados.

Si la empresa tiene varias sedes, elige en cuál se realizará la auditoría.

Selecciona una solicitud para consultar si ya tiene un periodo programado.

3. Configurar disponibilidad semanal

Recurrente por día
ℹ ¿Cómo funciona? Marca los días de la semana en los que puedes atender auditorías y define una franja horaria para cada uno. El rango de vigencia indica desde cuándo y hasta cuándo se repetirá este patrón. Puedes configurar varios días en una sola operación.

4. Registrar fecha no disponible

Bloqueo de día completo
ℹ Bloquea fechas completas para indicar que no podrás atender auditorías (permisos, incapacidades, vacaciones, etc.). El sistema verificará que no exista una auditoría programada en esas fechas antes de guardar el bloqueo.

No se permitirá registrar un bloqueo que se cruce con una auditoría ya programada.

5. Consultar y editar disponibilidad futura

ℹ Filtra y edita registros vigentes. Puedes consultar la disponibilidad por rango de fechas, tipo de registro o estado. Solo se pueden editar registros activos cuya vigencia no haya terminado; cada cambio guarda una instantánea en el historial.
Selecciona un auditor para consultar sus registros.
